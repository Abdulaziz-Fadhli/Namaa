# شاشات فيجما في الكود

الشاشات مبنية من ملف فيجما [نماء](https://www.figma.com/design/6VLNpDDzl8jWuuxaKt7ngO) (Page 1)، والتنقل بينها مطابق لروابط النموذج (Prototype) في الملف. الأرقام تأتي من محرك الفريق وليست منسوخة من التصميم.

## من أين تأتي الأرقام

| الرقم | المصدر |
|---|---|
| أرصدة الحسابات، الوعاء، النصاب، زكاة اليوم (165.35)، الوجوب التالي (بعد 13 يومًا)، شروح الأحداث، منحنى الرئيسية | `npm run view` يشغّل `runEngineDetailed` على بيانات أحمد ويحفظ `src/data/ahmad-view.json` |
| قيمة الذهب والفضة والنقد والعقار المضاف | `calculateAssetValue` من المحرك، بسعر الذهب والفضة في `prices.json` ليوم العرض |
| الأسهم والصناديق | `check` و`assess` و`toEngineEntry` من `src/securities` (حكم «هل يزكي؟») |
| زكاة الأصل المضاف يدويًا | تُضاف لزكاة اليوم إذا أكمل حولًا هجريًا من تاريخ تملكه (`isHawlComplete`) |

الاختبار `src/figma/view.test.js` يفشل إذا تغيّر المحرك أو البيانات ولم يُعَد توليد `ahmad-view.json`.

## الشاشات

| فيجما | المكوّن | يذهب إلى |
|---|---|---|
| بداية نماء | `Onboarding.Start` | ابدأ ← ربط الحسابات |
| ربط الحسابات | `Onboarding.Link` | إضافة بنك ← اختيار بنك، أعرف التاريخ ← تاريخ آخر زكاة، متابعة ← المزامنة |
| اختيار بنك / تاريخ آخر زكاة | `Onboarding.Bank` / `Onboarding.LastZakat` | حفظ ← رجوع |
| مزامنة الحسابات | `Onboarding.Sync` | متابعة ← الأصول خارج البنوك |
| الأصول خارج البنوك | `Assets.OffBank` | البطاقات ← شاشات الإضافة، حفظ ومتابعة ← الرئيسية |
| إضافة معادن / سهم أو صندوق / نقد / عقار | `Assets.Metals` / `Security` / `Assets.Cash` / `Assets.Property` | إضافة الأصل ← رجوع |
| الرئيسية | `Home.Home` | الجرس ← الإشعارات، المبلغ ← التفسير، شارة الوجوب ← الخط الزمني، الوعاء ← التفاصيل، النصاب ← الإعدادات |
| الإشعارات / الإعدادات / تفاصيل الأصول | `Home.Notifications` / `Home.SettingsScreen` / `Assets.Details` | حسب روابط فيجما |
| تفسير الزكاة / الخط الزمني | `Zakat.Explain` / `Zakat.Timeline` | إخراج الزكاة |
| إخراج الزكاة / اختيار القناة / النجاح | `Zakat.Payout` / `Zakat.Channel` / `Zakat.Success` | تأكيد ← الإيصال ← الرئيسية |

حالات فيجما الإضافية (لا أتذكر، ميلادي، فضة، صندوق) أزرار داخل نفس الشاشة وليست شاشات منفصلة.

## الملفات

- `figma.css`: الألوان والمقاسات من الملف، كلها تحت `.nm`.
- `ui.jsx`: المكونات المشتركة (شريط الحالة، شريط التطبيق، الصف، الأزرار، الخيارات، الحقول، الملاحظة، بطاقة المبلغ).
- `store.jsx` و`model.js`: حالة التجربة (الأصول المضافة، القناة، الإيصال) وثوابتها.
- الأيقونات من `lucide-react` بنفس أسمائها في فيجما، والشعار `src/assets/namaa-logo.png` مصدّر من الملف.
