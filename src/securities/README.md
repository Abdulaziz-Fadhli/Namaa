# «هل هذا السهم يزكي؟»

يكتب المستخدم اسم سهم أو صندوق أو رمزه في شاشة «أموال لا تراها البنوك»، فنخبره هل الورقة «تزكي» (الشركة تدفع الزكاة عنه) أو الزكاة عليه، ونحسب المبلغ إذا أدخل العدد والسعر.

## الملفات

| الملف | وظيفته |
|---|---|
| `src/securities/securities.js` | البحث والحكم والحساب، و`toEngineEntry` للربط مع `calculateAssetValue` في المحرك |
| `src/securities/securities.test.js` | 53 اختباراً، منها فحص شامل لكل ورقة في الدليل |
| `src/components/StockZakatCheck.jsx` | البطاقة في شاشة Manual (تُحمَّل عند فتح الشاشة فقط) |
| `src/data/securities.json` | الدليل المبني: 1614 ورقة |
| `scripts/securities-sources/*.csv` | مصادر الدليل. بعد أي تعديل: `npm run securities` ثم `npm test` |

## الأحكام

| الورقة | الحكم |
|---|---|
| شركة سعودية في تداول أو نمو | **يزكي** (أرامكو بالأمر الملكي 16712) |
| أي ورقة والمستخدم مضارب | الزكاة عليه على القيمة السوقية |
| شركة في تداول مسجلة خارج المملكة (أمريكانا) | لا يزكي |
| سهم في السوق الأمريكي | لا يزكي: 2.5% من القيمة السوقية |
| صندوق مؤشر أسهم سعودية | يزكي عبر شركاته |
| صندوق أسهم سعودية نشط غير مدرج | لا يزكي |
| ريت | لا يزكي: زكاة الوحدة من المدير، وإلا القيمة السوقية حداً أعلى |
| مرابحة، صكوك، سندات، ذهب، فضة، عملات رقمية، أسهم أجنبية، عقاري، متعدد الأصول | لا يزكي |

## الربط مع المحرك

```js
import { assess, toEngineEntry } from './securities/securities.js';
const e = toEngineEntry(assess({ symbol: 'AAPL', units: 10, price: 200 }));
// e = { kind: 'stocks', entry: { type: 'LONG_TERM', marketValue: 7500, zakatableValue: 7500 } }
calculateAssetValue({ [e.kind]: [e.entry] }); // 7500
```

سهم الشركة السعودية للمستثمر يرجع `zakatableValue: 0`، والصناديق ترجع في `investmentProducts`. المضارب يرجع `type: 'TRADING'` بالقيمة السوقية. ويقبل معرّفاً اختيارياً: `toEngineEntry(a, 'stock-1')`.
